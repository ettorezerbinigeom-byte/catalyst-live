# Catalyst Live

Pagina Streamlit con prezzi in tempo reale (Yahoo Finance) per seguire un piano di trading
su eventi binari (decisioni FDA e simili).

I dati del piano sono in `dati.enc`, cifrati: la pagina li apre solo con la chiave nei
Secrets di Streamlit, e si mostra solo con il codice d'accesso. Il codice e' generico.
